## Como vc vai fazer o versionamento com git

- vc vai pra página inicial do vs code e clica em Clone Git Repository...
- aí ele vai aparecer uma barrinha la em cima, vc aperta e procura o repositório que vc vai usar
- depois ele vai fala pra vc por em uma pasta e vc põem onde vc querer
- aí vc vai fazer as três pastas bonitinho com index.html, style.css e script.js
- vai abrir o terminal e dar git status e ver se todos os arquivos ta vermelho
- vai escrever git add . pra adicionar todos os arquivos de uma vez
- da git status pra ver se ta tudo verde 
- git commit -m "" e escreve oq vc fez 
- git push pra finalizar 
- ve se ta tudo certo no github
