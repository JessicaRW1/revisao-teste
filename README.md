## Como vc vai fazer o versionamento com git

1- vc vai pra página inicial do vs code e clica em Clone Git Repository...
2- aí ele vai aparecer uma barrinha la em cima, vc aperta e procura o repositório que vc vai usar
3- depois ele vai fala pra vc por em uma pasta e vc põem onde vc querer
4- aí vc vai fazer as três pastas bonitinho com index.html, style.css e script.js
5- vai abrir o terminal e dar git status e ver se todos os arquivos ta vermelho
6- vai escrever git add . pra adicionar todos os arquivos de uma vez
7- da git status pra ver se ta tudo verde 
8- git commit -m "" e escreve oq vc fez 
9- git push pra finalizar 
10- ve se ta tudo certo no github
